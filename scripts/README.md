# Scripts

Cartella riservata alla futura pipeline batch.

Componenti previsti:

- `collect/` — acquisizione;
- `normalize/` — testo e metadati;
- `deduplicate/` — copie e genealogia;
- `extract/` — entità e affermazioni;
- `verify/` — ricerca riscontri;
- `review/` — coda editoriale;
- `publish/` — JSON e sito statico.

Nessuno script deve pubblicare automaticamente accuse o contenuti giudiziari senza revisione.
