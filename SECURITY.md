# Sicurezza

Il repository non gestisce ancora segnalazioni sensibili.

Non inviare tramite issue pubbliche:

- identità di whistleblower;
- documenti non pubblici;
- credenziali;
- dati personali;
- leak;
- accuse non verificate.

Prima del lancio dovranno essere definiti un indirizzo di sicurezza, una procedura di disclosure e un canale protetto separato.
